# 🎵 PlayList — Músicas e Artistas

Um projeto web que reúne músicas de artistas conhecidos em uma página interativa, com imagens, controles de áudio e links para ouvir as faixas no Spotify.

## 📖 Sobre o projeto

O **PlayList** foi desenvolvido para praticar os fundamentos do desenvolvimento web enquanto organiza músicas de artistas como Michael Jackson e Bruno Mars em uma interface própria.

## ✨ Funcionalidades

- 🎧 Controles de áudio para ouvir as faixas disponíveis.
- 🖼️ Imagens relacionadas às músicas.
- 🎤 Organização das faixas por artista.
- 🔗 Links para músicas e perfis no Spotify.
- 🎨 Estilização personalizada com CSS.
- 🔤 Uso de fontes do Google Fonts.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura do conteúdo.
- **CSS3:** aparência e organização visual.
- **Google Fonts:** tipografia personalizada.
- **Áudio HTML:** reprodução de arquivos locais.

## 🚀 Como executar o projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/yhaguihara/PlayList.git
   ```
2. Entre na pasta:
   ```bash
   cd PlayList
   ```
3. Abra `index.html` no navegador. Para reproduzir as faixas locais, mantenha os arquivos de áudio dentro da pasta `music/`.

## 🎯 Objetivo de aprendizagem

Praticar HTML e CSS, trabalhar com imagens e áudio e integrar links externos em uma página web.
